# Dataset provenance

**digits.txt.** E. Alpaydin and C. Kaynak, *Optical Recognition of Handwritten Digits*, 1998, DOI 10.24432/C50P49. This file contains all 1,797 records of the test subset distributed by scikit-learn 1.6.1. Each original 8×8 feature grid counts ink in 4×4 regions of a scanned bitmap. The course preserves the labels, features, and order. It encodes 0–16 as one ASCII character each (`0123456789abcdefg`) and moves the label to the start of each line. The source data are CC BY 4.0. SHA-256 of the supplied file is `129eef24fe845dfb9ee752501689a6be3cb8afde16fdb4118c6ad9635b5545be`. [Original UCI dataset](https://doi.org/10.24432/C50P49) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [scikit-learn subset description](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)

**karate.mtx.** W. W. Zachary, “An Information Flow Model for Conflict and Fission in Small Groups,” *Journal of Anthropological Research* 33, 452–473 (1977). The file stores the 78 undirected friendship ties among 34 people. The course exported the undirected connectivity from NetworkX 3.4.2, discarded edge weights, converted node numbers to the Matrix Market one-based convention, and stored each tie once. The loader mirrors the ties to make 156 directed adjacency entries. The NetworkX license accompanies the data. [Original paper](https://doi.org/10.1086/jar.33.4.3629752) · [NetworkX data notes](https://networkx.org/documentation/stable/reference/generated/networkx.generators.social.karate_club_graph.html) · [SuiteSparse record](https://sparse.tamu.edu/Newman/karate)

**bcsstk14.mtx.** M. Will, Georgia Institute of Technology, Atlanta Omni Coliseum roof stiffness matrix, 1985. Harwell–Boeing collection, edited by I. Duff, R. Grimes and J. Lewis, SuiteSparse matrix 36. This is the complete Matrix Market file distributed with Trilinos release 17.1.1. Its original comments and bytes are preserved. It stores 32,630 lower triangular entries. Symmetric expansion yields 63,454 entries. SHA-256 is `4130d3bf6f881a4df4b22f2fd94bbf2f352e1bdb1d1ad20f4fcae64ec2ec448d`. [NIST archive record](https://math.nist.gov/MatrixMarket/data/Harwell-Boeing/bcsstruc2/bcsstk14.html) · [SuiteSparse record](https://sparse.tamu.edu/HB/bcsstk14) · [Trilinos file](https://raw.githubusercontent.com/trilinos/Trilinos/trilinos-release-17-1-1/packages/belos/testmatrices/bcsstk14.mtx)
