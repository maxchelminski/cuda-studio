Dataset provenance

digits.txt. E. Alpaydin and C. Kaynak, Optical Recognition of Handwritten Digits, 1998, DOI 10.24432/C50P49. This file contains all 1,797 records of the test subset distributed by scikit-learn 1.6.1. Each original 8×8 feature grid counts ink in 4×4 regions of a scanned bitmap. The course preserves the labels, features, and order. It encodes 0–16 as one ASCII character each (0123456789abcdefg) and moves the label to the start of each line. The source data are CC BY 4.0. SHA-256 of the supplied file is 129eef24fe845dfb9ee752501689a6be3cb8afde16fdb4118c6ad9635b5545be. Original UCI dataset · CC BY 4.0 · scikit-learn subset description

karate.mtx. W. W. Zachary, “An Information Flow Model for Conflict and Fission in Small Groups,” Journal of Anthropological Research 33, 452–473 (1977). The file stores the 78 undirected friendship ties among 34 people. The course exported the undirected connectivity from NetworkX 3.4.2, discarded edge weights, converted node numbers to the Matrix Market one-based convention, and stored each tie once. The loader mirrors the ties to make 156 directed adjacency entries. The NetworkX license accompanies the data. Original paper · NetworkX data notes · SuiteSparse record

bcsstk14.mtx. M. Will, Georgia Institute of Technology, Atlanta Omni Coliseum roof stiffness matrix, 1985. Harwell–Boeing collection, edited by I. Duff, R. Grimes and J. Lewis, SuiteSparse matrix 36. This is the complete Matrix Market file distributed with Trilinos release 17.1.1. Its original comments and bytes are preserved. It stores 32,630 lower triangular entries. Symmetric expansion yields 63,454 entries. SHA-256 is 4130d3bf6f881a4df4b22f2fd94bbf2f352e1bdb1d1ad20f4fcae64ec2ec448d. NIST archive record · SuiteSparse record · Trilinos file
