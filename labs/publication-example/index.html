Why does the same 1 keep winning?

One handwritten 1 was the nearest match for 30 of 360 searches. It gave the wrong answer 20 times. What makes a single gallery image so attractive to a dot product?

Change the score. Keep the gallery.

For each query, pick the highest-scoring gallery image and predict its digit. The first 1,437 rows form the gallery. The final 360 rows are the queries. Every comparison uses the same 64 ink counts.

dot(q, g) = ‖q‖ × ‖g‖ × cosine(q, g)

With the query fixed, a large gallery norm can compensate for poorer alignment. Dividing each gallery vector by its length removes that advantage. Dividing the query by its own length then converts scores to cosine similarities without changing their order.

Where CUDA enters

The native course lab stacks the queries into a 360 × 64 matrix and the gallery into a 64 × 1,437 matrix. Multiplying these normalized arrays gives all 517,320 cosine scores. In the RTX 5070 course check, cuBLAS FP32 and TF32-allowed each produced 343 correct labels. Matching aggregate counts still leaves open which individual predictions agree.

A follow-on experiment. Before changing precision, predict which queries will be most sensitive. Save the top two FP32 scores and their gallery IDs for each query. Group queries by the gap between the two scores, rerun with TF32 allowed, and measure where the winning row or digit changes. A group with zero changes is an informative result.

Reproduce the evidence

The Python reference compares integer dot products and squared cosine ratios exactly. Equal scores select the earliest gallery row. The comparison uses a fixed split within the UCI test file and measures accuracy on these queries. Writer-independent generalization needs a separate evaluation.

From the course root, run the first command to regenerate this report. Add --rows winners.csv to export every query and both winning gallery IDs and labels. The second command repeats the separate GPU accuracy check in the course PowerShell.

python labs/publication-example/reproduce.py
.\build\compute\Release\compute_lab.exe digits 1797

Outside the course, save the script and extract optdigits.tes from the UCI download. Run the following in that directory with Python 3.8 or newer. Analysis script · UCI download and description

python reproduce.py --data optdigits.tes --output index.html --rows winners.csv
